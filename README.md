# 🚀 ED Overlay

**ED Overlay** is a lightweight, modular **AutoHotkey v2 overlay toolkit** for *Elite Dangerous*. It parses Journal logs to provide real-time, transparent HUD overlays for navigation, combat metrics, and system notices.

---

## 💡 Key Features

* **Lightweight**: Minimal CPU footprint with zero impact on in-game performance.
* **Clean HUD**: Click-through, transparent overlays designed to match the *Elite Dangerous* UI.

---

## 🛠️ Core Modules

* **`ED_Status.ahk`**: Tracks FSD jumps, route steps, and system arrivals with custom audio signals (`SoundBeep`).
* **`ED_PowerCZ.ahk`**: Real-time Merit and CP estimations, kill counts, and Powerplay CZ progress.

---

## 🚀 Quick Start

1. Install **AutoHotkey v2**.
2. Clone this repo:
```bash
git clone https://github.com/YOUR_USERNAME/ED-Overlay.git

```


3. Run `ED_Status.ahk` or `ED_PowerCZ.ahk` while playing *Elite Dangerous*.
